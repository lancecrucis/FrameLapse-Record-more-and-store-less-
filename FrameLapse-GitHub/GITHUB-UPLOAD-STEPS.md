# Upload this project to GitHub

1. Sign in at https://github.com and choose **New repository**.
2. Name it `FrameLapse`, choose **Public**, and do not add another README, license, or `.gitignore`.
3. Create the repository, then choose **uploading an existing file**.
4. Open this `FrameLapse-GitHub` folder and drag all of its contents into the GitHub upload area.
5. Wait until every file is listed, enter a commit message such as `Initial FrameLapse release`, and choose **Commit changes**.

The large FFmpeg and FFprobe executables are intentionally not in this folder because GitHub rejects individual files over 100 MB. Their required locations and redistribution notes are documented in `tools/README.md`.

Before publishing, read `ASSET-NOTICE.md` and confirm that you have the rights needed to distribute every visual asset.
